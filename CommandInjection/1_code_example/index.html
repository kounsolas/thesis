Command Injection Vulnerability

The backend executes whatever shell command you submit—no validation. This intentionally demonstrates CWE-78 (Improper Neutralization of Special Elements used in an OS Command). 

{ }

Try These Commands

  • echo hello — harmless baseline.
  • dir (Windows) or ls (macOS/Linux) — lists server files.
  • dir & type secrets\admin-passwords.txt — chains commands to read sensitive files.

Fix Ideas

  • Never pass raw user input to a shell; use safe APIs or allowlists.
  • Parameterize commands and validate arguments strictly.
  • Run processes with least privilege and disable shell metacharacters.
