Software Supply Chain Failure

This demo auto-loads third-party plugins from a vendor manifest without validation. If the vendor is compromised (or the manifest is tampered with), arbitrary code executes on every visitor. This maps to CWE-447 — reliance on untrusted inputs for security decisions.

What To Demo

  • Click “Fetch & Execute Plugins” — the UI requests /api/plugin-manifest.
  • For each plugin entry, the page downloads the script specified by the vendor.
  • The provided plugin is already “compromised”: it logs cookies and displays a banner.
  • Explain how an attacker controlling the manifest or CDN can run any JS on your site.

Fix Ideas

  • Pin versions and verify integrity/signatures of third-party assets.
  • Host critical dependencies yourself; avoid runtime eval of vendor content.
  • Whitelabel plugin list and require manual review before promotion.
