Eval / Code Injection

This demo sends arbitrary JavaScript to the server, which evaluates it with eval(). Anyone can run code on the server, illustrating CWE-95 (Improper Neutralization of Directives in Dynamically Evaluated Code).

Try These Snippets

  • 2 + 2 — benign arithmetic.
  • process.cwd() — reveals server info.
  • require('fs').readdirSync('.') — lists files on the server.
  • require('child_process').execSync('dir').toString() — escalates to command execution.

Fix Ideas

  • Never run untrusted code via eval, Function, or similar interpreters.
  • Use safe interpreters or sandboxing if dynamic logic is required.
  • Provide a curated set of operations (allowlist) instead of arbitrary code.
