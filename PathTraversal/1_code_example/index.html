Path Traversal Vulnerability

The download endpoint trusts the ?file= parameter and joins it directly with the server's files/ directory. Attackers can supply ../ segments to escape and read sensitive files. 

{ }

Try These Inputs

  • public-note.txt — legitimate file.
  • ../secrets/admin-passwords.txt — escapes the directory (path traversal).

Fix Ideas

  • Normalize and validate requested paths; reject any containing .. or absolute paths.
  • Use allowlists or map file identifiers to actual filenames server-side.
  • Run downloads under least privilege and separate sensitive data from public directories.
