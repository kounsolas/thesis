Security Misconfiguration

This demo intentionally leaves debug mode enabled and exposes sensitive configuration files through static hosting. Use it to show why hardening defaults and disabling debug features in production is critical.

Debug Endpoint Left Enabled

Click the button to call /api/debug/info. In real deployments this should be disabled, but a misconfiguration exposes environment variables and secrets.

Sensitive Files Served Publicly

Because the server serves the entire folder statically, you can read config/secret-config.json directly.

Teaching Ideas

  • Explain why debug endpoints should be guarded by environment toggles and authentication.
  • Show how default/static hosting configuration can leak sensitive files.
  • Discuss best practices: least privilege, deny-by-default, environment-specific configs.
